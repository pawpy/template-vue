# Vue starter

A minimal [Vue](https://vuejs.org) single-page app built with Vite. The build output in `dist/` is static and can be served by any web server; `dist/health` answers health checks.

## Run it locally

```sh
npm install
npm run dev        # development
npm run build      # static files in dist/
```

## Deploying

| Step | Command |
| --- | --- |
| Build | npm run build |
| Start | serve `dist/` as static files |
